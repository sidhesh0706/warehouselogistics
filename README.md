# Smart Warehouse Logistics

Smart Warehouse Logistics is a database-driven inventory and fulfilment system built for warehouse operations. It tracks stock across multiple locations, records product movement, supports order shipment, restores inventory when orders are removed, and raises automated alerts for low-stock and expiry risk.

The project is designed as a final-year DBMS submission and portfolio project, with a clean relational schema, SQLite triggers, transactional inventory updates, and a browser-based operations dashboard.

## Highlights

- Multi-warehouse inventory monitoring with bin-level stock records.
- Supplier, product, warehouse, inventory, order, and movement tables.
- Receiving, shipping, and inter-warehouse transfer workflows.
- Order removal flow that restores shipped stock and records an adjustment movement.
- Low-stock reorder alerts generated by SQLite triggers.
- Expiry alerts for perishable inventory within 30 days.
- Shelf-space utilization view based on warehouse capacity.
- Responsive frontend dashboard built with HTML, CSS, and JavaScript.
- Dependency-light Python backend using the standard library and SQLite.

## Tech Stack

- Backend: Python HTTP server

## Main Tables

- `suppliers`: supplier contact and address details.
- `products`: SKU, category, price, supplier, reorder level, and expiry flag.
- `warehouses`: location, capacity, manager, and warehouse status.
- `inventory`: stock quantity by product, warehouse, bin, and expiry date.
- `orders`: customer shipments with quantity and total amount.
- `stock_movements`: receiving, shipping, transfer, and adjustment history.
- `reorder_alerts`: trigger-created low-stock alerts.
- `expiry_alerts`: trigger-created expiry risk alerts.

## Database Logic

- Shipping an order deducts stock using earliest-expiry inventory first.
- Removing an order restores stock to the source warehouse under a `RETURNS` bin.
- Receiving and transfers update inventory immediately.
- Inventory changes trigger low-stock checks against each product's reorder level.
- Expiry alerts are created when stock expires within 30 days.

## Why This Project Matters

Warehouses often lose efficiency through poor stock visibility, delayed reorder decisions, and weak expiry tracking. This system shows how a relational database can support real operational workflows: stock movement, replenishment, fulfilment, order correction, and inventory risk monitoring.
